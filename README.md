# Artificial Intelligence Lab - Prolog Codes

This repository contains Prolog programs and laboratory assignments implemented for the **Artificial Intelligence Lab.**

## 📋 List of Programs

1. **GCD and LCM (`gcd_lcm.pl`):** Find the Greatest Common Divisor and Least Common Multiple of two numbers.
2. **Fibonacci Series (`fibonacci.pl`):** Find the nth number of the Fibonacci series.
3. **Factorial (`factorial.pl`):** Calculate the factorial of a given number.
4. **Cube of a Number (`cube.pl`):** Demonstrate the cube of a number using interactive input.
5. **List Operations (`insert_list.pl`, `delete_list.pl`):** Perform basic operations on lists like insertion and deletion.
6. **Bubble Sort (`bubblesort.pl`):** Sort a list of numbers using the Bubble Sort algorithm.
7. **File Handling (`file_handle.pl`):** Read data from one file and write it to another file.

## 🚀 How to Run

1. Install [SWI-Prolog](https://www.swi-prolog.org/Download.html) on your system.
2. Open the SWI-Prolog console.
3. Load a specific file using the `consult` command:
   ```prolog
   ?- consult('filename.pl').
   ```
